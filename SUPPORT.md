# Support

Use GitHub Issues for reproducible bugs and feature requests for Steve's Music Requests.

## Bugs

When reporting a bug, include:

- Steve version or release artifact name.
- Windows version.
- Whether you installed with the `.exe` installer or zip fallback.
- Which area is affected: Twitch auth/chat/EventSub, song requests, Mixxx, OBS Browser Sources, Now Playing, announcements, event queue, alerts, Quick Actions, character output, audio, install/update, or runtime folder setup.
- Expected behavior.
- Actual behavior.
- Steps to reproduce.
- Relevant log excerpts with secrets removed.

## Setup Help

For setup problems, include only the specific failing step. Do not paste full runtime folders or full logs.

Useful details include:

- Whether Twitch authorization completed.
- Whether Mixxx is installed and live broadcasting if testing Now Playing metadata.
- The OBS Browser Source URL path, with private details removed if needed.
- Whether the runtime folder was moved.

## Sensitive Information

Do not post Twitch tokens, authorization files, full logs, private music-library listings, personal data, or user-provided assets you cannot redistribute.

## Security Issues

For suspected security vulnerabilities, follow [SECURITY.md](SECURITY.md) instead of opening a public issue.
